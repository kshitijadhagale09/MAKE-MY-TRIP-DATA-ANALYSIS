# ✈️ MakeMyTrip Travel Data Analysis & Dashboard

## 📊 Project Overview

This project focuses on analyzing **MakeMyTrip travel booking data** to identify important business insights related to bookings, revenue, destinations, traveler demographics, booking platforms, airlines, and customer satisfaction.

An interactive **Travel Dashboard** was created to transform raw booking data into meaningful visual insights and Key Performance Indicators (KPIs).

The dashboard provides a consolidated view of travel booking performance and allows users to analyze trends based on factors such as:

- 📅 Booking Date
- 📍 Destination
- 👥 Traveler Type
- ✈️ Airline
- 💻 Booking Channel
- 💰 Booking Value
- ⭐ Customer Rating

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze overall travel booking performance.
2. Identify booking and revenue trends over time.
3. Analyze the most popular travel destinations.
4. Understand different traveler segments.
5. Compare booking channels such as Website, Mobile App, and Travel Agent.
6. Analyze airline booking performance.
7. Measure customer satisfaction using ratings.
8. Build an interactive dashboard for business-oriented decision making.
9. Convert raw travel data into clear and actionable visual insights.

---

## 📁 Dataset

The dataset contains **100,000 travel booking records** with the following fields:

| Column | Description |
|--------|-------------|
| `Booking_ID` | Unique identifier for each booking |
| `Booking_Date` | Date on which the booking was made |
| `Destination` | Travel destination |
| `State` | State/region associated with the booking |
| `Airline` | Airline selected for the booking |
| `Traveler_Type` | Type of traveler such as Solo, Family, Business, or Couple |
| `Booking_Channel` | Platform used for booking |
| `Booking_Value` | Monetary value of the booking |
| `Customer_Rating` | Customer satisfaction rating |

### Dataset Statistics

- **Total Records:** 100,000
- **Total Columns:** 9
- **Date Range:** January 2022 – December 2024
- **Destinations:** 10
- **Airlines:** 6
- **Booking Channels:** 3
- **Traveler Types:** 4

---

## 📌 Key Performance Indicators (KPIs)

The dashboard tracks the following major KPIs:

### 🧾 Total Bookings
Total number of travel bookings available in the selected date range and filters.

### 💰 Total Revenue
Total booking value generated from all travel bookings.

### 💵 Average Booking Value
Average monetary value generated per booking.

### ⭐ Customer Satisfaction
Average customer rating based on booking feedback.

## 📊 Dashboard Features

The dashboard contains multiple visualizations to provide a complete overview of travel booking performance.

### 1. 📈 Booking Trend

The Booking Trend visualization shows monthly booking activity and revenue trends.

It helps analyze:

- Monthly booking volume
- Revenue movement
- Seasonal patterns
- Changes in booking activity

---

### 2. 📍 Top Destinations

The Top Destinations chart displays destinations based on booking volume.

This helps identify:

- Popular travel destinations
- High-demand locations
- Destination-level booking performance

---

### 3. 👥 Traveler Demographics

The Traveler Demographics visualization presents the distribution of different traveler categories:

- Solo
- Family
- Business
- Couple

This provides insight into customer segmentation and travel behavior.

---

### 4. 💻 Booking Platform Analysis

The Booking Platform visualization compares bookings made through:

- Website
- Mobile App
- Travel Agent

This helps understand customer preferences for different booking channels.

---

### 5. ✈️ Top Airline Analysis

The Top Airline visualization compares booking activity across different airlines.

It provides insight into airline-level booking performance and customer selection patterns.

---

### 6. ⭐ Customer Satisfaction

Customer ratings are analyzed to understand overall satisfaction levels.

The dashboard uses the average customer rating as a key indicator of customer experience.

## 🎛️ Dashboard Filters

The dashboard includes interactive filters that allow users to explore the data dynamically.

### Date Range
Users can select a specific booking period.

### Destination
Filter the analysis based on individual destinations.

### Traveler Type
Analyze bookings based on traveler categories.

These filters allow users to drill down into specific segments and understand their performance.
